# 正式周报同步模块

## 职责

只接收企业微信工作汇总项目生成的正式周报 Markdown，通过不可见的 `BOARD_SYNC` JSON 状态块确定性同步事项，不调用任何AI模型。

## 流程

```text
上传 YYYY-Www.md
→ 解析 BOARD_SYNC
→ 生成稳定事项键
→ 新增 / 更新 / 关闭 / 跳过重复 / 标记冲突
→ 写入SQLite和变更历史
```

## 状态映射

| 周报状态 | 看板状态 |
|---|---|
| 继续跟进 | in_progress |
| 已闭环 | completed |
| 无需跟进 | deferred |
| 仅作周报进展 | 不创建新任务；已有任务只更新进展 |

## 安全边界

- 仅接受 `.md`，最大5MB。
- 缺少或无法解析 `BOARD_SYNC` 时拒绝导入。
- 较旧周报不得覆盖较新周报状态。
- 上传完成后立即删除临时文件。
